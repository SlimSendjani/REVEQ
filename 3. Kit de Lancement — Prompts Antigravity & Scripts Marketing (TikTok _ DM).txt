1. Guide de Build dans Antigravity — 5 Prompts Prêts à Copier-Coller
Prompt 1 : Initialisation, Design System & Landing Page Bilingue
Tu es un ingénieur Fullstack Senior expert en Next.js App Router, Tailwind CSS et Supabase. Nous construisons un SaaS B2B de gestion de la réputation pour les commerces locaux au Québec.


Objectif du Prompt 1 : Configurer le projet, le design system et une landing page bilingue (FR/EN) avec démo interactive.


1. Configuration & Structure :
- Initialise l'architecture Next.js 14+ (App Router, TypeScript).
- Installe et configure Tailwind CSS avec la palette exacte :
  * Fond principal : Blanc (#FFFFFF)
  * Texte principal : Noir profond (#000000) et Ardoise (#1E293B)
  * Couleur d'accentuation : Sarcelle moderne (#0E7470)
  * Gradients & Neutral Borders : Accents légers en #F1F5F9 et #E2E8F0
- Utilise la police 'Inter' via next/font/google.


2. Système d'Internationalisation (i18n) :
- Met en place un système i18n ultra-léger basé sur un dictionnaire (FR / EN). Le Québec a besoin d'une conformité stricte à la Loi 96, donc la langue par défaut DOIT être le français.


3. Hero Section & Démo Interactive :
- Crée un composant 'Hero section' dynamique.
- Intègre une démo interactive directement testable dans le Hero :
  * Affichage d'une fausse fiche de commerce ("Café Le Petit Saint-Denis").
  * Sélecteur 5 étoiles interactif.
  * Si l'utilisateur clique sur 4 ou 5 étoiles : Animation fluide vers un bouton "Redirection Google Maps simulée".
  * Si l'utilisateur clique sur 1, 2 ou 3 étoiles : Transition vers un formulaire de retour privé ("Expliquez-nous le problème avant d'en informer le public").


4. Sections de la Landing Page :
- Section Problème/Solution (Comparaison entre recevoir un avis 1 étoile public vs recevoir une alerte privée).
- Section Tarification bilingue (29$/mois Essentiel, 49$/mois Pro, Plan Annuel avec 2 mois gratuits).
- Footer avec mentions légales et basculeur de langue FR/EN.

Prompt 2 : Auth, Base de Données & Onboarding en 3 minutes
Poursuis le projet Next.js. Nous allons configurer la base de données Supabase, l'authentification et l'onboarding rapide des commerçants.


1. Configuration Schéma Supabase DB (SQL) :
Crée les tables suivantes avec la sécurité RLS (Row Level Security) activée :
- `profiles` : id (uuid, references auth.users), email (text), full_name (text), created_at (timestamp).
- `businesses` : id (uuid), user_id (references profiles.id), name (text), slug (text, unique), logo_url (text), google_maps_url (text), phone (text), email_notifications (text), subscription_status (text: 'active', 'trialing', 'canceled'), created_at (timestamp).
- `private_feedback` : id (uuid), business_id (references businesses.id), rating (int), customer_name (text), customer_email (text), customer_phone (text), message (text), created_at (timestamp).


2. Supabase Storage :
- Configure un bucket public `business-logos` avec RLS permettant la lecture publique et l'écriture uniquement par le propriétaire.


3. Flow d'Authentification (Supabase Auth) :
- Implémente la connexion via Email/Mot de passe et Magic Link (Supabase Auth UI ou composants personnalisés Tailwind).


4. Onboarding Commerçant en 3 Étapes (Formulaire Réactif avec Preview) :
- Étape 1 : Nom du commerce, ville, et génération automatique du `slug` unique (ex: "Boutique Fleurie" -> "boutique-fleurie-mtl").
- Étape 2 : Lien de la fiche Google Maps et upload du logo avec redimensionnement automatique côté client.
- Étape 3 : Aperçu en temps réel (layout scindé : à gauche les champs, à droite un composant Frame Mobile simulant l'expérience du client final).

Prompt 3 : Page Publique /[slug] & Mode Kiosque /kiosk/[slug]
t
Construis les pages publiques de capture d'avis, optimisées pour la rapidité sur mobile (Mobile-First UI).


1. Logique de la route /[slug] :
* Récupère les données du commerce via le slug. Si l'abonnement du commerce (subscription_status) est invalide ou annulé, affiche une page élégante indiquant que la page est temporairement indisponible.
* Affiche le logo du commerce, le nom et le titre : "Comment s'est passée votre expérience aujourd'hui ?"
* Composant 5 étoiles tactiles de grande taille (haute réponse au toucher mobile).
2. Routage Intelligent (Le Cœur du Produit) :
* Sélection de 4 ou 5 étoiles : Redirection immédiate vers l'URL google_maps_url inscrite dans la base de données.
* Sélection de 1, 2 ou 3 étoiles : Ouverture d'un formulaire épuré sans rechargement de page :
   * Champs : Nom, Courriel, Téléphone (optionnel), et "Comment pouvons-nous améliorer notre service ?"
   * Bouton "Envoyer à la direction".
   * Soumission : Enregistre dans private_feedback et déclenche une API route qui envoie une alerte Resend au propriétaire.
3. Mode Écran de Comptoir /kiosk/[slug] :
* Une vue plein écran sans aucun défilement, conçue pour être laissée sur une tablette (iPad/Android) installée au comptoir du commerce, se réinitialisant automatiquement 10 secondes après chaque avis soumis.
4. Conformité Strictement Respectée (Google Guidelines) :
* Ajoute en bas de page un lien discret et conforme aux politiques Google : "Laisser un avis directement sur Google".
